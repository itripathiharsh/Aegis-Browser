### What's New in Nivrok v1.0.10
- First installable **LG webOS TV `.ipk`** (`io.github.itripathiharsh.nivrok_1.0.10_all.ipk` / `Nivrok-v1.0.10.ipk`) packaged for Developer Mode testing on LG Smart TVs.
- Bundled pure-Node.js LG webOS Luna loopback ad-blocking service (`io.github.itripathiharsh.nivrok.service`) using 53,000+ EasyList, EasyPrivacy, uBlock, and Cosmetic filter rules with frame-header stripping, cosmetic hiding, popup blocking, and HTML5 media `Range` streaming.
- Full TV remote (`Back` / D-Pad / `PalmServiceBridge`) navigation, live viewport browsing, persisted bookmarks/history/settings/tabs on webOS, and synchronized Android APK release build.
